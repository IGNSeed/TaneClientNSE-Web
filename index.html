Installation

The package is arranged for direct extraction to the root of your SD card.

  1. 01

    Download

    Download the latest release ZIP.

  2. 02

    Extract

    Back up existing files if needed, then extract the ZIP to the root of your Nintendo Switch SD card.

  3. 03

    Confirm

    Confirm that both files are under:

    atmosphere/contents/01006BD001E06000/exefs/
  4. 04

    Launch

    Start Minecraft: Nintendo Switch Edition through Atmosphère.

03

Requirements

  • Nintendo Switch capable of running Atmosphère
  • Minecraft: Nintendo Switch Edition
  • Access to the Nintendo Switch SD card

Supported Title ID 01006BD001E06000

04

Stable updates

TaneClient checks for stable updates when Minecraft starts. When an update is available, it is downloaded and verified automatically.

Minecraft closes after installation so the updated client can be loaded the next time you launch the game.

An internet connection is only required to check for updates.
